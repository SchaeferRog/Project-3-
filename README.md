The overall goal of this group is to assist the professional engineer (PE) in understanding transportation usage and system performance to further help the client – Federal Highway Administration (FHWA). This prokect identifys and visualizes trends from the National Household Travel Survey (NHTS) and the Next Generation Simulation (NGSIM) databases that could help assist transportation planning firms. The background and signifigance of this data, as well as visual aids (bar chart, histogram, boxplot, etc.), are expanded upon in the Project Report. The group will assist by providing valuable insights concerning the characteristics of transportation usage and driving behavior. The subgoals of this group are broken down below.

Goal 1 – Analyze and Understand Transportation Data
The group will need to examine travel behavior trends using data from the National Household Travel Survey (NHTS). This includes analyzing driver behavior and vehicle performance using the Next Generation Simulation (NGSIM), as well as identifying key variables that are meaningful for transportation planning.

Goal 2 – Help Develop Clear and Informative Visualizations
This project requires the group to create certain plots (bar chart, histogram, boxplot, and time-series graphs). These visualizations will be customized through the python libraries: matplotlib and seaborn. The results must be presented in a way that is capable of properly informing those making decisions for the Federal Highway Administration.

Goal 3 – Demonstrate Technical and Analytical Skills
The group is tasked with using Python to efficiently clean and analyze large datasets. Then they must conduct a simulation using the Intelligent Driver Model (IDM). During the course of the work, it is important to clearly document code, simulation findings, and time spent to evaluate workflow efficiency.

More information on this project can be found in the Scope of Work and Project Report.
